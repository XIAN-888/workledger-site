Hourlume 隐私政策

生效日期：2026年11月12日

Hourlume 帮你记录客户工作、整理对账单和登记收款。工作数据保存在你的设备上。我们不运营接收客户姓名、联系方式、备注、工时、金额或导出文档的服务器。

本机保存的数据

App 在自身存储空间中保存客户、工作、对账单、收款记录及本地恢复副本。个人与示例工作区相互独立。App 无需账户，没有广告、追踪、使用分析、第三方分析 SDK 或 AI 处理。我们不出售你的个人数据。

你主动保存或分享的文件

PDF、CSV 和 JSON 文件可能包含客户及工作信息。你通过 Apple 的“文件”和分享面板自行选择保存或分享位置。你选择的目标可能是云服务或其他 App，其隐私规则由对应服务决定。设备备份设置也可能将 App 数据纳入 Apple 设备备份。

App 没有自动云同步或跨设备同步。在 iPhone 与 iPad 之间搬迁记录，需要你自行传输和恢复 JSON 备份。恢复会替换所选工作区，不会合并设备上的记录。

通过 Apple 购买

付款及恢复购买由 Apple 处理。App 使用 StoreKit 验证年费订阅或买断权益。我们不接收或保存你的支付卡信息。Apple 的数据处理方式见 Apple 隐私政策。

你可以在 Apple 账户设置中管理或取消年费。买断不会自动取消已有的年费订阅。

本地导出权限记录

为记住已完成的免费导出及已解锁对账单，App 会在仅限本设备的 iOS 钥匙串中保存随机分配的对账单标识（UUID）及免费或 Pro 解锁类型。该记录不含客户姓名或对账单金额，也不会发送给我们；在本设备恢复旧备份时，它还可防止前三份免费额度被重置。

JSON 备份保留其中每份对账单的解锁状态。将这样的备份恢复到另一台设备后，对应对账单仍保持解锁。这是用户主动传输文件，并非钥匙串或 App 自动同步。

管理和删除

你可以编辑或归档客户、恢复最近删除的工作、撤销收款记录，以及导出 JSON 备份。删除 App 会移除其存储空间中的记录；本地钥匙串中的导出权限标识可能保留。已导出的文件会继续保存在你选择的位置，请在对应目标中管理这些副本。
