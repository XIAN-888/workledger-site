働いた時間も、未入金も、わかりやすく。

取引先ごとの作業、明細書、入金記録を、iPhone や iPad でひとまとめに。

作業時間から、見やすい明細書へ

タイマーで計測することも、完了した作業を手入力することもできます。未処理の作業を明細書にまとめ、プレビューして PDF や CSV で共有できます。

未入金の残高を確認

端末上で入金の資料を確認し、実際に受け取った金額を明示的に確認してから、同じ顧客の未払い明細書へ古い順に割り当てます。期間別の照合では、通貨ごとの期首・期末未収残高を確認できます。送金は行いません。

記録は手元のデバイスに

アプリ用アカウント、広告、利用状況分析はありません。資料の文字認識は端末上の Apple Vision で行い、画像や認識文字を認識サーバーへ送信しません。JSON バックアップには保存済み資料のコピーも含まれます。iPhone と iPad に対応し、Mac 版はありません。

自分の作業で無料体験

取引先の管理、作業時間の記録、プレビューは無料です。異なる正式な明細書を最初の3件まで無料で書き出せます。それ以降の新しい明細書には Pro が必要です。サンプルの書き出しと JSON のバックアップ・復元は常に無料です。
