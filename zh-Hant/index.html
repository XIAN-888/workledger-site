記清工時，看清未收款。

Work log 將客戶工作、對帳單和收款紀錄放在一起，隨時用 iPhone 或 iPad 查看。

從工時到清楚的對帳單

開始計時或手動補登已完成的工作，將未出單工作整理成對帳單，預覽後分享 PDF 或 CSV。

還有多少未收，一眼看清

登記已收到的全款或部分款項，查看剩餘未收餘額。收款紀錄不會執行轉帳。

紀錄留在你手中

不需帳號，沒有廣告、分析服務或 AI 處理。資料儲存在本機，你可以用 JSON 備份自行搬移。支援 iPhone 和 iPad，不提供 Mac 版本。

用自己的工作免費體驗

免費管理客戶、記錄工時和預覽。前三份不同的正式對帳單可免費匯出，之後的新對帳單需 Pro。範例匯出、JSON 備份與還原始終免費。
