Hourlume 지원

작업 기록부터 정산서 작성까지 차근차근 시작하세요. Hourlume는 iPhone과 iPad용이며 Mac 버전은 없습니다.

고객 추가하기

고객과 시간당 요금을 추가한 뒤 타이머를 시작하거나 완료한 작업을 직접 입력하세요. 나중에 고객의 기본 요금이나 통화를 바꾸더라도 이미 저장한 작업의 요금과 통화는 유지됩니다.

정산서 작성 및 공유

한 고객의 같은 통화로 기록된 미정산 작업을 선택하세요. PDF를 미리 본 뒤 Apple 공유 시트에서 PDF나 CSV를 저장하거나 공유할 수 있습니다. 앱이 정산서를 자동으로 발송하지는 않습니다.

정산서에 포함된 작업은 잠깁니다. 입금 기록이 없는 정산서는 무효화하여 작업을 다시 수정할 수 있습니다. 정산서는 작업 내역을 기록하는 문서이며 세금계산서가 아닙니다. 앱은 결제를 처리하지 않습니다.

실제로 받은 금액 기록

사진 또는 파일에서 증빙 이미지를 선택하면 Apple Vision이 기기에서 문자, 금액, 통화, 날짜 후보를 제안합니다. 원본을 읽고 값을 수정한 다음 실제로 돈을 받았음을 명확히 확인하세요. OCR은 진위, 이체 또는 은행 입금을 인증하지 않습니다. 누락되거나 음수이거나 모호한 값은 직접 입력해야 할 수 있습니다.

저장 전에 같은 고객·통화의 오래된 미수 정산서부터 배분 내역을 검토합니다. 모든 배분은 한 건의 입금으로 함께 저장됩니다. 일부 배분을 취소하면 입금 전체와 모든 배분이 함께 취소되고 이력은 보존되며 실제 환불은 하지 않습니다. 동일 원본 이미지는 중복 등록할 수 없고 다른 중복 후보도 확인해야 합니다. 저장 전 취소하면 장부에 증빙이 추가되지 않습니다.

기간 잔액 이해하기

고객에서 고객을 선택한 뒤 고객 거래 대조를 여세요(화면 제목: 거래 대조). 통화와 기간을 선택하세요. 원본 정산서, 입금과 취소, 날짜가 기록된 무효 처리, 기초·기말 미수 잔액을 확인합니다. 다른 통화와 아직 정산하지 않은 작업은 분리됩니다. 과거 무효 처리에 날짜가 없으면 이력을 만들어 내지 않고 과거 잔액을 확인할 수 없다고 표시합니다.

정산서 3건 무료 내보내기

고객 관리, 작업 시간 기록, 미리 보기는 무료입니다. 서로 다른 정식 정산서 3건까지 무료로 내보낼 수 있습니다. 저장 또는 공유가 성공했을 때만 1건으로 계산하며, 미리 보기나 공유 시트 취소는 횟수를 사용하지 않습니다.

무료 횟수나 Pro로 한 번 정상적으로 내보내 잠금 해제한 정산서는 연간 구독이 끝난 뒤에도 추가 횟수 없이 다시 내보낼 수 있습니다. 같은 정산서의 PDF와 CSV는 잠금 해제 상태를 공유합니다. 예시 정산서와 JSON 백업·복원은 항상 무료입니다.

대사 미리보기는 무료입니다. 통합 PDF·CSV 공유는 샘플, 유효한 Pro, 또는 포함된 모든 정산서에 영구 내보내기 권한이 있을 때 가능합니다. 새 횟수를 쓰거나 아직 내보내지 않은 정산서를 잠금 해제하지 않습니다. 권한이 없으면 원래 정산서 내보내기 또는 Pro 절차를 먼저 이용하세요. 기존 3건 규칙은 유지됩니다.

연간 구독 또는 평생 이용 Pro

Pro는 무료 횟수 이후에도 새 정산서를 내보낼 수 있게 합니다. 자동 갱신되는 연간 구독과 한 번 결제하는 평생 이용권 중 선택할 수 있습니다. 가격 및 청구 조건은 앱과 Apple 확인 화면에 표시되는 해당 스토어 정보를 따릅니다.

구매에 사용한 Apple 계정으로 설정 → Pro → 구매 복원을 여세요. 연간 구독 관리·취소는 Apple 계정의 구독 설정에서 할 수 있습니다. 평생 이용권을 구매해도 기존 연간 구독은 자동으로 취소되지 않습니다. 갱신을 원하지 않으면 별도로 취소하세요. 결제와 구매 복원은 Apple이 처리하며 Apple 표준 EULA가 적용됩니다.

백업 또는 다른 기기로 이동

자동 클라우드 동기화나 기기 간 자동 동기화는 없습니다. iPhone과 iPad 사이에서 기록을 옮기려면 JSON 백업을 직접 전송하고 복원하세요. 복원은 선택한 작업 공간을 덮어쓰며 기존 기록과 합치지 않습니다. 언어와 정산서 발신자 설정은 백업에 포함되지 않습니다.

전체 JSON 백업에는 작업 공간 기록 외에 축소된 증빙 이미지, 인식 문자, 확인한 필드와 입금 배분이 포함됩니다. 비공개 금융 자료로 보관하고 복원 후 증빙 첨부도 확인하세요.

인코딩된 전체 백업 한도는 256 MB, 저장된 증빙 이미지 한 개의 한도는 8 MB입니다. 한도 오류는 기존 기록을 변경하지 않으며 필요하면 지원팀에 문의하세요. 업그레이드 전 백업을 보관하세요. 이전 앱은 업그레이드된 기록을 안전하게 열 수 없으므로 이전 버전으로 돌아가려면 업그레이드 전 백업을 복원해야 합니다.

  1. 원래 기기에서 설정 → 백업을 파일 앱에 저장을 열고 저장 위치를 선택하세요.
  2. 파일 앱이나 AirDrop 등으로 해당 JSON 파일을 새 기기에 전송하세요.
  3. 새 기기에 보관할 기록이 있으면 먼저 백업하세요. 설정 → 백업 복원에서 내용을 확인하고 덮어쓰기를 확정하세요.
  4. 복원 후 고객, 작업, 정산서, 입금을 확인하세요. 예시와 개인 작업 공간은 분리되어 있으므로 백업에 맞는 작업 공간에 복원하세요.

앱은 기본적으로 시스템 언어를 따릅니다. 설정에서 미국 영어, 영국 영어, 중국어 간체, 중국어 번체, 일본어, 독일어, 한국어, 스페인어를 직접 고를 수도 있습니다. 이 웹사이트는 기본적으로 미국 영어로 열리며 언어 링크로 전환할 수 있습니다.
