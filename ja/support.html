Hourlume サポート

作業の記録から明細書の作成まで、順を追って進められます。Hourlume は iPhone と iPad 用です。Mac 版はありません。

取引先を登録する

取引先と時間単価を登録し、タイマーを開始するか、完了した作業を手入力します。後から取引先の既定の単価や通貨を変更しても、保存済みの作業に記録された単価や通貨は変わりません。

明細書を作成して共有する

同じ取引先・同じ通貨の未処理の作業を選びます。PDF をプレビューし、Apple の共有シートで PDF または CSV を保存・共有できます。アプリが明細書を自動送信することはありません。

明細書に含めた作業は編集できなくなります。入金記録がない明細書は無効にして作業を解放し、修正できます。明細書は作業の記録であり、税務用の請求書ではありません。アプリは決済を処理しません。

受け取ったお金を記録する

実際に受け取った全額または一部の入金を記録すると、未入金の残高が更新されます。誤った入金記録は取り消して、履歴を残したまま残高を修正できます。入金の記録や取り消しによって、送金や返金が行われることはありません。

最初の3件は無料で書き出し

取引先管理、作業時間の記録、プレビューは無料です。異なる正式な明細書を最初の3件まで無料で書き出せます。保存または共有が成功したときだけ1件として数えられ、プレビューや共有シートのキャンセルでは消費されません。

無料枠または Pro で一度正常に書き出してロック解除した明細書は、年額サブスクリプション終了後も、追加の無料枠を使わず繰り返し書き出せます。同じ明細書の PDF と CSV は共通の解除状態を使います。サンプル明細書と JSON のバックアップ・復元は常に無料です。

年額プランと買い切り Pro

Pro では、無料枠を使った後も新しい明細書を書き出せます。自動更新の年額サブスクリプションまたは一度の支払いによる買い切りを選べます。価格と課金内容は、アプリと Apple の確認画面に表示される、お使いのストアの情報が適用されます。

購入時の Apple Account で「設定 → Pro → 購入を復元」を開くと購入を復元できます。年額プランの管理・解約は Apple Account のサブスクリプション設定で行ってください。買い切りを購入しても既存の年額プランは自動解約されません。更新を希望しない場合は別途解約してください。支払いと購入の復元は Apple が処理し、Apple 標準 EULA が適用されます。

バックアップとデバイス間の移行

自動クラウド同期やデバイス間の自動同期はありません。iPhone と iPad の間で記録を移すには、JSON バックアップを自分で転送・復元します。復元は選択したワークスペースを置き換える操作で、データの統合は行いません。言語と明細書の差出人設定はバックアップに含まれません。

  1. 移行元で設定 → バックアップを「ファイル」に保存を開き、保存先を選びます。
  2. 「ファイル」や AirDrop などで、その JSON ファイルを移行先に転送します。
  3. 移行先に残したい記録がある場合は先にバックアップします。「設定 → バックアップを復元」で内容を確認し、置き換えを確定します。
  4. 復元後に取引先、作業、明細書、入金を確認します。サンプルと個人用のワークスペースは別々です。バックアップと一致するワークスペースに復元してください。

言語を選ぶ

アプリは既定でシステムの言語に従います。設定から、米国英語、英国英語、簡体字中国語、繁体字中国語、日本語、ドイツ語、韓国語、スペイン語を選択することもできます。このサイトは既定で米国英語が開き、言語リンクで切り替えられます。
