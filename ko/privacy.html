Work log 개인정보 처리방침

시행일: 2026년 11월 12일

Work log는 고객 작업 기록, 정산서 작성, 입금 관리를 돕습니다. 작업 기록은 사용자의 기기에 저장됩니다. 당사는 고객 이름, 연락처, 메모, 작업 시간, 금액 또는 내보낸 문서를 수신하는 서버를 운영하지 않습니다.

기기에 저장되는 기록

앱은 고객, 작업, 정산서, 입금 기록과 로컬 복구 사본을 앱 자체 저장 공간에 보관합니다. 개인 작업 공간과 예시 작업 공간은 분리되어 있습니다. 앱 계정, 광고, 추적, 이용 분석, 타사 분석 SDK 또는 AI 처리는 없습니다. 당사는 개인정보를 판매하지 않습니다.

직접 저장하거나 공유하는 파일

PDF, CSV, JSON에는 고객 및 작업 정보가 포함될 수 있습니다. Apple의 파일 앱이나 공유 시트에서 저장·공유할 위치를 직접 선택합니다. 선택한 클라우드 서비스나 다른 앱에는 해당 서비스의 개인정보 처리방침이 적용됩니다. 기기 백업 설정에 따라 앱 데이터가 Apple 기기 백업에 포함될 수도 있습니다.

앱에는 자동 클라우드 동기화나 기기 간 자동 동기화가 없습니다. iPhone과 iPad 간 기록 이동에는 직접 전송하고 복원하는 JSON 백업이 필요합니다. 복원은 선택한 작업 공간을 덮어쓰며 두 기기의 데이터를 합치지 않습니다.

Apple을 통한 구매

결제와 구매 복원은 Apple이 처리합니다. 앱은 StoreKit으로 연간 구독이나 평생 이용권의 이용 권한을 검증합니다. 당사는 결제 카드 정보를 받거나 저장하지 않습니다. Apple의 처리 방식은 Apple 개인정보 처리방침에서 확인할 수 있습니다.

연간 구독은 Apple 계정 설정에서 관리하거나 취소할 수 있습니다. 평생 이용권을 구매해도 기존 연간 구독은 자동으로 취소되지 않습니다.

로컬 내보내기 권한 기록

완료한 무료 내보내기와 이미 잠금 해제한 정산서를 기억하기 위해, 앱은 무작위로 지정된 정산서 식별자(UUID)와 무료 또는 Pro 잠금 해제 유형을 이 기기 전용 iOS 키체인에 저장합니다. 여기에는 고객 이름이나 정산 금액이 포함되지 않으며 당사로 전송되지 않습니다. 같은 기기에 오래된 백업을 복원해도 무료 정산서 3건의 사용 내역이 초기화되지 않도록 하는 용도도 있습니다.

JSON 백업에는 포함된 각 정산서의 잠금 해제 상태가 저장됩니다. 다른 기기에 해당 백업을 복원하면 그 정산서들은 잠금 해제 상태를 유지합니다. 이는 사용자가 직접 수행하는 파일 전송이며 키체인이나 앱의 자동 동기화가 아닙니다.

관리 및 삭제

고객을 수정·보관하고, 최근 삭제한 작업을 복원하며, 입금 기록을 취소하고 JSON 백업을 내보낼 수 있습니다. 앱을 삭제하면 앱 저장 공간의 기록은 삭제되지만 키체인의 로컬 내보내기 권한 식별자는 남을 수 있습니다. 내보낸 파일은 저장하거나 공유한 위치에 남으므로 해당 위치에서 사본을 관리하세요.
